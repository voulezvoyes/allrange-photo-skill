# 친구에게 그대로 보내기

AllrangeKit 사이트에 사용할 인물 사진 프롬프트를 쉽게 만들 수 있도록 Codex 스킬을 만들어뒀어.

**처음 한 번만 할 일**
1. 컴퓨터에서 ChatGPT 데스크톱 앱을 켜서 **Codex**로 이동해줘. ChatGPT Plus 계정으로 로그인하면 돼.
2. 내가 보내준 GitHub 링크를 넣고 다음 메시지를 Codex에 보내줘.

```text
$skill-installer 이 GitHub 저장소의 allrange-photo 스킬을 설치해줘: [내가 보낸 GitHub 링크]/tree/main/skills/allrange-photo
```

3. 설치되면 Codex에서 새 대화를 시작해줘. 안 보이면 앱을 재실행해봐.

**사진을 만들 때마다 할 일**

```text
$allrange-photo
[사진 용도]: 홈페이지 배너
[인물]: 30대 동아시아계 여성 1명
[행동]: 집 소파에 앉아 휴대폰을 보는 장면
[장소]: 자동
[의상]: 자동
[시간·조명]: 자동
[카메라 구도]: 자동
[글씨 넣을 공간]: 오른쪽
```

필수로 바꿀 건 **사진 용도, 인물, 행동** 세 개뿐이야. 나머지는 자동으로 둬도 돼. Codex가 영문 프롬프트를 만들어주면 그걸 일반 ChatGPT의 이미지 생성 채팅에 복사해서 사진 만들면 끝.

각도가 똑같이 나오면 Codex에 "이번엔 어깨너머 구도로", "이번엔 조금 멀리서", "인물을 왼쪽에 배치하고 오른쪽은 글씨 공간으로"라고 말하면 돼.

**중요:** 실제 제품 사진이나 회사 로고가 필요할 때는 AI가 만들어낸 가짜 제품을 쓰지 말고 회사에서 승인한 원본 파일을 사용해줘. 사진을 공개하기 전에 얼굴·손·배경 오류와 회사의 의료 광고 기준도 확인해줘.
